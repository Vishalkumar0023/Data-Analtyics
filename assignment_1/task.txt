Part 1 – Database Creation (15 marks)
Task 1. Create a database named company_hr.

Inside this database, create a table named employees with these columns:
Column	Data type
employee_id	SERIAL PRIMARY KEY
employee_name	VARCHAR(80)
email	VARCHAR(120)
department	VARCHAR(40)
job_title	VARCHAR(60)
hire_date	DATE
salary	INTEGER
employment_status	VARCHAR(20)

Requirements:
1. Employee ID must be automatically generated.
2. Employee name and email must not accept NULL values.
3. Email must be unique.
4. Salary must initially use INTEGER.

Part 3 – Retrieve and Verify Data (10 marks)
Task 3. Write SQL queries to:
1. Display all employee records.
2. Display only employee name, department and salary.
3. Display employees in descending order of salary.
4. Display employees belonging to the Engineering department.
5. Find employees whose salary is between ₹40,000 and ₹70,000.

Part 4 – Update Employee Records (20 marks)
Task 4. HR has requested the following changes:
1. Increase the salary of every Engineering employee by 8%.
2. Change Kabir Khan's department from Sales to Business Development.
3. Change Kunal Singh's job title to Junior Data Analyst.
4. Update Kunal Singh's salary to ₹25,000.
5. Change Simran Kaur's employment status to On Leave.
6. Correct Aarav Mehta's job title to Java Backend Developer.
Company expectation: Before every UPDATE operation, write a SELECT query using the same condition to verify which records will be affected.
